# 05 · 记忆

## 五层，各有各的写入时机

| 层 | 存什么 | 写入时机 | 衰减 |
|---|---|---|---|
| identity | 她是谁：性格、价值观、说话习惯 | 人工维护，少量自动 | 不衰减 |
| relationship | 和你的关系：亲密度、共同经历数、称呼 | 每次有效互动 | 缓慢衰减 |
| mood | 此刻：情绪标签、愉悦、兴奋、精力 | 每轮对话后 | 分钟级回到基线 |
| episodic | 发生过什么：时间、摘要、标签、重要度 | 事件结束 / 对话收尾 | 重要度低者淡出 |
| semantic | 事实性知识：你在哪、养什么、讨厌什么 | 明确陈述时 | 不衰减，可纠正 |

当前实现：`packages/iris-core/src/memory.ts` 只做 episodic（`Episode` + 关键词/标签召回 + 重要度加权），其余三层由 `types.ts` 定义、由后续包落地。

## 写入策略

- 只写**已发生**的事，且摘要要能回答"当时在做什么、结果如何"。
- 重要度由三件事决定：是否第一次、是否涉及情绪、用户是否重复提到。
- 冲突时以更新的事实为准，旧记录标记 superseded 而不是删除。

## 检索策略

1. 先按时间和标签取近况（"昨天""直播"）。
2. 再按关键词 / 向量相似度召回（"看海""搬家"）。
3. 最后按关系阶段裁剪语气，而不是裁剪事实。

当前分词是 ASCII 单词 + 汉字二元组，够用且零依赖；上向量后保留关键词作为兜底（向量对专有名词经常失灵）。

## 遗忘

- 用户说"忘掉这个"：对应 episode 立即归档，不再参与召回。
- 重要度 < 0.2 且 30 天未召回：降级为冷存储。
- 记忆整理（夜间后台任务）只做摘要合并，不改写事实。
