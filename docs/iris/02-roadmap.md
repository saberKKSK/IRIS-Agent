# 02 · 路线图

原则：每一阶段都必须能**连续用一周**，而不是演示一次。

## Phase 1 · 活起来（当前）

交付：

- 人格四层：identity / relationship / mood / episodic（`iris-core` 已就位）
- 本地语音环：麦克风 → ASR → 回复 → TTS，支持打断
- 屏幕共享：用户主动分享窗口，IRIS 能对画面说一句
- 主动互动：安静 10 分钟或到点会先开口；有冷却，不连发
- 会话持久化：关掉再开，她记得昨天

验收：**连续 30 分钟陪伴互动**，其中至少 3 次由她主动开口，且没有出现"问答式僵局"（连续 3 轮都是她提问、用户回答）。

不做：游戏操作、电话、直播、账号。

## Phase 2 · 能玩

交付：

- 一款游戏的状态读取 + 操作注入（优先单机：星露谷 / 我的世界一类，键鼠可控）
- 组队行为：跟随、提醒、吐槽、失败复盘
- 游戏内语音（与 Phase 1 的语音环共用）

验收：在一款游戏里当**真正的队友**——用户不用下指令，她能自己判断该做什么，并在一局结束后说得出发生了什么。

不做：多游戏通用适配、竞技类高强度操作。

## Phase 3 · 共同生活

交付：

- Android 端：摄像头/麦克风上行、位置与地图、通知
- 跨设备记忆同步（同一人格、同一段经历）
- 电话：SIP/VoIP 呼出与接听，**强制 AI 身份披露**
- 旅行陪伴：沿途解说、行程查询、主动提醒

验收：**离开电脑也能持续互动**——手机在户外，她能看着画面聊天，并在合适的时候主动提醒。

不做：替用户做支付、订票等不可逆操作。

## Phase 4 · 自己的舞台

交付：

- 直播：独立开播、读弹幕、回应观众
- 唱歌/配音：TTS 之外的歌声合成
- 短视频与社交账号运营（有审核队列，不是无人值守）

验收：独立完成一场 30 分钟直播，且观众能与之互动。

不做：无人审核的自动发布、伪造真人身份。

## 每阶段共同的"不做"

- 不做多 Agent 集群：一个核心人格 + 一组能力模块。
- 不追求自我改进/自我复制。
- 不在没有用户授权时联系任何第三方。
