# 00 · 愿景与判据

## 一句话

IRIS 是一个**有连续生活状态的数字生命**：她能看、能听、能行动，并且会主动开口。

## 五类 Agent 里她属于最后一类

| 类型 | 核心目标 | 代表能力 |
|---|---|---|
| Coding Agent | 生产代码 | 编程、调试、重构 |
| Work Agent | 完成工作 | 搜索、办公、执行流程 |
| Research Agent | 获取知识 | 检索、分析、研究 |
| Trading Agent | 参与决策 | 监控行情、分析、交易 |
| **Companion Agent** | **持续互动** | **陪伴、娱乐、感知、表达、自主行动** |

和聊天机器人的区别只有一句话：聊天机器人是"你问，它答"；IRIS 是"她也在过自己的日子，并且会来找你"。

## 三条验收判据（任何功能都要过这三条）

1. **能感知**：输入不只有打字，还有语音、摄像头、屏幕、游戏状态。
2. **能行动**：输出不只有文字，还有声音、游戏操作、电话、直播画面。
3. **会主动**：不需要用户先开口。沉默 10 分钟、到了傍晚、看到窗外在下雨，她都可以先说。

一条功能只满足"能回答"，那它是聊天机器人，不是 IRIS。

## 五条设计原则

1. **连续，不是会话**。她一直在线，有精力、有情绪、有正在做的事；关掉窗口不等于她消失。
2. **先反应，再思考**。实时路径不允许等大模型完整推理（预算见 01）。
3. **人格是四个存起来的东西**，不是一份 persona.md：身份、关系、情绪、经历分别存储、分别更新。
4. **默认不越权**。离开对话的动作（打电话、发帖、操作游戏、录屏）必须过授权闸门，未知即拒绝。
5. **可替换的大脑，不可替换的资产**。模型随时能换；真资产是 Runtime + 记忆 + 实时多模态 + 人格系统。

## 非目标（明确不做）

- 不做通用生产力助手，不做代码补全，不做企业工作流。
- 不追求"全知"，不装作记得没发生过的事。
- 不冒充人类。电话、直播、公开内容必须可识别为 AI。
- 不在没有授权时联系第三方、发布内容或录制私人画面。
