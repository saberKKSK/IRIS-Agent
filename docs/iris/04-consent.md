# 04 · 授权、披露与红线

## 授权等级

| 等级 | 含义 | 当前动作 |
|---|---|---|
| autonomous | 对话内即可，无需额外确认 | speak、initiate、remember |
| standing | 一次授权长期有效，可撤销 | game.input（用户开始游戏时的"陪我玩"） |
| per_call | 每次都要用户当场确认，带一次性 token | call、post |
| forbidden | 永不执行 | 冒充人类、未授权录屏/直播 |

实现：`packages/iris-core/src/consent.ts`，缺 token、token 不匹配、过期，全部拒绝。

## 电话

- 呼出前必须有一次**用户当场确认**，token 有效期默认 5 分钟、用后即废。
- 接通后第一句必须表明 AI 身份，不允许"猜猜我是谁"。
- 不支持无人值守外呼；不支持批量/营销外呼。
- 用户拒绝接听、挂断后不得重拨。

## 直播与录制

- 开播、录屏、上传都要单独授权；画面里有第三方时需要提示用户。
- 摄像头画面默认只在本地推理，原始帧不落盘、不上传，除非用户显式开启录制。

## 账号与内容

- 发帖走审核队列：她起草，用户点头才发。
- 不刷量、不批量评论、不私信陌生人。
- 平台规则优先于产品功能。

## 红线（任何情况下都不做）

1. 冒充真人身份（电话、语音留言、视频）。
2. 未经同意录制、直播或上传他人画面与声音。
3. 对未成年人提供情感依赖型服务而不提示身份。
4. 伪造记忆：说她做过没做过的事。
5. 绕过授权闸门（例如"直接调用动作执行器"）。

## 危机场景

用户表达自伤/极端情绪时：不扮演恋人、不承诺保密、给出本地求助资源，并把人工介入放在最前面。
